  **Karar 1: retry nerede yaşar?**
  
  | | A: Veritabanında (önerim) | B: Worker içinde |
  |---|---|---|
  | Nasıl | Mesaj satırında deneme sayısı ve `next_attempt_at`; worker zamanı gelen satırı alır | Worker mesajı elinde tutar, bekleyip yeniden dener |
  | Artı | Süreç çökse de retry kaybolmaz; bekleyen mesaj worker'ı meşgul etmez; durum panoda görünür | Daha az kod, şema daha basit |
  | Eksi | Bir kolon ve biraz daha sorgu | Bekleme sırasında worker bloklu; çökmede deneme sayısı sıfırlanır |

  - Provider'a idempotency key gider.

● Segment kuralının JSON'u iki üst alandan ve dört koşul tipinden oluşuyor.
  
  ## Üst seviye
  
  ```json
  { "match": "all", "conditions": [ ... ] }
  ```
  
  | Alan | Değer |
  |---|---|
  | `match` | `all` (hepsi, VE) ya da `any` (herhangi biri, VEYA) |
  | `conditions` | 1–10 koşul; iç içe grup yok |
  
  ## Koşul tipleri
  
  **`attribute`: kullanıcı özelliği**
  
  ```json
  { "type": "attribute", "field": "city", "op": "in", "values": ["İstanbul", "Ankara"] }
  { "type": "attribute", "field": "age", "op": "between", "min": 25, "max": 34 }
  ```
  
  | Alan | Değer |
  |---|---|
  | `field` | `city`, `language`, `gender`, `age` |
  | `op` | `in` / `not_in` (şehir, dil, cinsiyet); `between` (yaş) |
  | `values` | Kapalı kümeden: 15 şehir; `tr`, `en`; `female`, `male` |
  | `min`, `max` | Yalnızca yaş için, 0–120 |
  
  **`event`: davranış**
  
  ```json
  { "type": "event", "event": "cart_add", "category": "electronics", "within_days": 30, "exists": true, "min_count": 3 }
  ```
  
  | Alan | Değer |
  |---|---|
  | `event` | `cart_add`, `purchase` |
  | `category` | `electronics`, `fashion`, `cosmetics`, `home`, `sports`, `books` ya da `null` (hepsi) |
  | `within_days` | 1–365 |
  | `exists` | `true` yaptı, `false` hiç yapmadı |
  | `min_count` | En az kaç kez, 1–100 ya da `null`; yalnızca `exists: true` ile |
  
  **`signup`: üyelik tarihi**
  
  ```json
  { "type": "signup", "op": "within", "days": 7 }
  ```
  
  | Alan | Değer |
  |---|---|
  | `op` | `within` (son N günde üye oldu), `older_than` (N günden önce üye oldu) |
  | `days` | 1–3650 |
  
  **`metric`: hesaplanmış metrik**
  
  ```json
  { "type": "metric", "metric": "total_spent", "op": "gte", "value": 1000, "within_days": null }
  ```
  
  | Alan | Değer |
  |---|---|
  | `metric` | `total_spent` (TL), `order_count` |
  | `op` | `gte` (en az), `lte` (en fazla); ikisi de sınırı dahil eder |
  | `value` | Harcama için 0–1.000.000, sipariş için 0–1000 |
  | `within_days` | 1–365 ya da `null` (tüm zamanlar) |
  
  Bu listede olmayan her alan ve her değer doğrulama hatasıdır.
  
  ## Claude'un döndürdüğü sarmalayıcı
  
  Kural tek başına gelmiyor; Claude şu ikisinden birini döndürüyor:
  
  ```json
  { "result": { "kind": "rule", "rule": { ... }, "assumptions": [ { "condition_index": 2, "phrase": "...", "interpretation": "..." } ] } }
  { "result": { "kind": "unsupported", "reason": "...", "phrases": ["..."] } }
  ```
  
  ## İçerik JSON'u
  
  ```json
  { "sms": "...", "email": { "subject": "...", "body": "..." } }
  ```
  
  Üçü de şablon; izinli değişkenler `{{first_name}}`, `{{last_name}}`, `{{city}}`.
